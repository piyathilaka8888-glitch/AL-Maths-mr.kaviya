# 📝 Past Paper Completion Rule

A past paper is **NOT complete** just because the questions were read.

### A Past Paper is Complete When:

* [ ] Paper attempted under a time limit
* [ ] Paper marked
* [ ] Score recorded
* [ ] Mistakes identified
* [ ] Weak areas identified
* [ ] Wrong questions re-done
* [ ] Correct methods understood

### Not Complete If:

* [ ] Only questions were read
* [ ] Paper was stopped without recording progress
* [ ] Answers were checked before attempting
* [ ] Paper was marked without reviewing mistakes
